# RFID Smart Billing System

Automated billing system using RFID sensors with data validation.

## Publication
Published in TIJER International Journal (2024)
[Read Paper](docs/rfid-billing-journal.pdf)

## Components
- RFID reader and tags
- Microcontroller (add your board)
- Display / software (add yours)

## How It Works
1. RFID tag on product is scanned
2. Data is validated
3. Bill is generated automatically
